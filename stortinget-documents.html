Direkte data fra Stortinget

Skriftlige spørsmål, interpellasjoner og spørretimespørsmål

Stortingsdokumenter uten egen backend

Denne siden henter ferske spørsmål direkte fra Stortingets åpne API. Alt kjører i nettleseren, så du kan publisere løsningen på GitHub Pages eller andre statiske tjenester uten å sette opp en server.

Forespørslene er delt i de tre hovedtypene for spørsmål slik Stortinget organiserer dem: skriftlige spørsmål, interpellasjoner og spørretimespørsmål.

Klikk «Hent spørsmål» for å laste data fra Stortinget.

Slik publiserer du på GitHub Pages

  1. Legg denne HTML-filen og JavaScript-filen i repoet ditt og sørg for at de versjoneres i Git.
  2. Push endringene til main-branchen (eller den grenen GitHub Pages bygger fra).
  3. Aktiver GitHub Pages under Settings > Pages og velg riktig kilde (for eksempel «Deploy from a branch»).
  4. Når GitHub Pages er aktivert, blir siden tilgjengelig på https://<brukernavn>.github.io/<repo>/stortinget-documents.html.
  5. Besøk adressen for å starte henting av data direkte i nettleseren.
Data hentes fra Stortingets åpne API ved hver forespørsel. Ingen data lagres på server-siden.
